# Bundled fonts

JetBrains Mono Nerd Font Regular and Bold identify themselves as JetBrains Mono
2.304, patched with Nerd Fonts 3.4.0. Their font metadata declares the SIL Open
Font License 1.1; the original copyright and license are included in `OFL.txt`.
`NERD-FONTS-LICENSE.txt` preserves Nerd Fonts' additional source notices.

Sources:
- https://github.com/JetBrains/JetBrainsMono/tree/v2.304
- https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/JetBrainsMono
